# fractalSwing — changelog

Only the latest APK is kept in this repo. Every version installs over the previous one and keeps your presets.

## 1.0.0 — First build · 2026-11-06
- 11 fractal families on the GPU, each in Julia or Mandelbrot form.
- 16 live swings with 8 wave shapes, phase, audio links, global swing speed/amount, drift and freeze.
- Colour engine: smooth iteration, orbit trap, stripes, angle; 9 palettes incl. custom; inside colouring.
- FX: kaleidoscope and mirrors, glow, video feedback (trails / screen / echo), chromatic aberration, vignette, grain, scanlines.
- Audio sync from the phone's output with a beat detector and 7 mappings.
- 12 presets, user presets, randomize / same-fractal-new-look / mutate, copy/paste settings, snapshots, adaptive render resolution.
- Web version (WebGL2) with the same shaders, panel and settings format.
